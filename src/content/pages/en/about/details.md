Kumpa’s app and server share a [public code repository](https://github.com/kuutti-ry/kumpa-app). You can read how matching works, report a bug or suggest a change there.

## How it’s built

The iPhone and Android app uses React Native and Expo. The server uses TypeScript and PostgreSQL. Identification goes through the Finnish Trust Network via Telia. The servers, database and photo storage are in Germany.

The code is available under the [GNU Affero General Public License](https://github.com/kuutti-ry/kumpa-app/blob/main/LICENSE) with an [app store exception](https://github.com/kuutti-ry/kumpa-app/blob/main/LICENSE-EXCEPTION).

## Service status

[Check the API status](https://api.kumpa.fi/health). The response shows whether the server can reach its database and which version of the code is running.

## Research

Supporting research into relationships and loneliness is part of the association’s purpose. Kumpa currently has no research partner and collects no data for research.
